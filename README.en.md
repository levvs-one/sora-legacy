# Sora Legacy

[Русский](README.md)

A separate Sora client for older Windows, developed in the `legacy` branch. The current Windows and Linux client is in [sora](https://github.com/levvs-one/sora).

The new legacy client is not released yet. Native .NET Framework 4.8 x86/x64 checks cover service access without administrator rights, the main screen, 31 interface languages and closing the app. These checks ran on modern Windows; Windows 7 SP1 and 8.1 runtime compatibility still needs verification.
