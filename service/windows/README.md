# service/windows

Интеграция службы ядра `SoraLegacyCore` с Windows (целевые системы
репозитория — Windows 7 SP1 и новее). Код службы находится в
`core/cmd/sora-core`; в этом каталоге пока только этот README —
отдельных скриптов здесь нет.

Что уже реализовано в коде ядра, а не здесь:

- Регистрация службы: сама служба (`sora-core --install-service`,
  имя `SoraLegacyCore` в `core/cmd/sora-core/service_windows.go`);
  установщик продукта службу не ставит.
- Именованный канал управления — `\\.\pipe\sora-legacy-core-v1`
  (`core/ipc/ipc_windows.go`), доступ ограничен дескриптором канала
  и проверкой вызывающей стороны в `core/ipc`.
- Wintun поставляется в payload комплекта установщика
  (см. `legacy/build/Stage-Release.ps1`), а не этим каталогом.
- Фильтры WFP kill switch реализует `core/guard` на Windows;
  снятие фильтров при остановке — обязанность ядра.
