# Sora Legacy

Разработка нового клиента идёт в [отдельном репозитории sora-legacy](https://github.com/levvs-one/sora-legacy), в ветке `legacy`.

Новый интерфейс находится в `Client`, транспорт службы — в `Control`. Прежний клиент сохранён в `v2rayN`; его сборки не являются готовым новым legacy-клиентом.
