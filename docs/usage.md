# Использование

Всё ниже — поставляемый клиент на базе v2rayN (`sora_<цель>.exe`). Новый клиент (`legacy/Client`) в установочный комплект не входит, и здесь не описывается. Установка, обновление и удаление — в [install.md](install.md).

## Добавление подписок и серверов

Одно поле добавления принимает и само определяет формат:

- ссылку HTTPS-подписки;
- отдельную ссылку сервера: VMess, VLESS, Trojan, Shadowsocks, SOCKS;
- Base64-блок, SIP008 и Xray JSON — массив полных конфигураций Xray импортируется отдельными серверами с исходными названиями.

Небезопасная HTTP-подписка не сохраняется как успешно добавленная: интерфейс сразу требует HTTPS. Поле импорта принимает до 4 МБ.

Подписки живут на экране серверов отдельными сворачиваемыми секциями. Название, описание, лимит трафика, срок действия, обновление и проверка задержки относятся к конкретной подписке. Ранее импортированные серверы без принадлежности находятся в отдельной локальной подписке. Неудачное обновление подписки не удаляет ранее сохранённые серверы.

Ссылки `sora://` клиент сегодня не обрабатывает: установщик регистрацию уже делает, но переход по такой ссылке пока молча игнорируется — добавляйте подписку вставкой в поле импорта.

## Выбор сервера и подключение

- Двойной щелчок по строке выбирает активный сервер; `Enter` в списке делает то же.
- Режимы подключения: системный прокси и TUN (через tun2proxy в комплекте). Режим сразу отражается в кнопке режима `Прокси`/`TUN`.
- Проверка задержки измеряет прямое TCP-соединение с адресом сервера и показывает состояние проверки для каждой строки.
- Командная строка: `--silent` — запуск без окна, в трей; `--tun` — старт с режимом TUN; `--wait-for <pid>` — дождаться завершения процесса. Полный контракт — в [install.md](install.md#командная-строка-поставляемого-клиента).
- Запущен может быть один экземпляр на путь исполняемого файла: второй запуск активирует окно работающего.

## Журнал и диагностика

- Журнал показывает вкладки событий клиента; выбранная вкладка сохраняется в UTF-8, текст можно скопировать.
- Безопасный диагностический архив собирается отдельным действием: в него не попадают конфигурации подключения, ссылки подписок, UUID и адреса серверов. Именно этот архив прикладывайте к сообщению об ошибке.
- Резервные копии настроек и экспортированные файлы клиент сохраняет в собственные каталоги (`guiBackups` и соседние в каталоге установки), а не системными диалогами выбора файла.

## Обновление

Самообновления у клиента нет: пункт проверки обновлений открывает страницу релизов в браузере. Обновление — ручная установка новой версии поверх старой; настройки и подписки при этом сохраняются. Подробности и честные границы обновления ядер из интерфейса — в [install.md](install.md#обновление).
