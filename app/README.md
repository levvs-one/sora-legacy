# app

**Честный статус: это скелет, а не приложение.** В дереве лежат только
сгенерированный Dart-код контракта `sora.core.v1`
(`lib/src/generated/`), `analysis_options.yaml` и спека Android-туннеля
(`android/tunnel/README.md`). Нет ни `pubspec.yaml`, ни одного экрана —
Flutter-приложение из этого дерева не собирается, и за существующее
его выдавать нельзя. Настоящие клиенты этого репозитория —
`legacy/Client` (Windows), `android/`, `macos/`, `ios/`; полноценное
Flutter-дерево есть у основного поколения sora.

Ниже — замысел на случай, если Flutter-приложение в этом поколении
всё же появится: оно работало бы от имени пользователя, хранило бы
подписки и настройки и управляло бы ядром только через контракт
`sora.core.v1`.

## Что здесь будет

| Каталог | Назначение |
| --- | --- |
| `lib/src/shell` | Оболочка приложения, навигация, первый запуск, настройки |
| `lib/src/design` | Дизайн-система: токены, тема, адаптивная раскладка, виджеты |
| `lib/src/core_client` | Клиент ядра с переподключением |
| `lib/src/store` | Хранилище профилей на drift и защищенное хранилище секретов |
| `lib/src/features` | Экраны функций: подключение, серверы, подписки, маршрутизация, диагностика |
| `lib/l10n` | Строки интерфейса на русском и английском |
| `android/tunnel` | Android-служба туннеля |

## Правила

- Интерфейс не выполняет работу на каждый пакет трафика. Тяжелый разбор выполняется вне основного isolate.
- Настройки анализатора заданы в `analysis_options.yaml`.
