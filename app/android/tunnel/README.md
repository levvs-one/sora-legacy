# app/android/tunnel

**Статус: спека, не код.** В этом каталоге только этот README; службы
туннеля здесь нет. Настоящий Android-клиент этого репозитория живёт в
`android/` (свой `SoraVpnService` на Kotlin поверх libbox пина
sing-box 1.12.12 и `core/mobileapi`). Ниже — замысел службы для
Flutter-приложения из `app/`, которого пока не существует: служба
`SoraVpnService` на Kotlin, работающая в отдельном процессе
`:tunnel`, загружающая `libsora` через AAR из gomobile и держащая
подключение, даже когда интерфейс закрыт.

## Что здесь будет

- `SoraVpnService`: получение TUN от `VpnService.Builder`, правила по приложениям, защита исходящих сокетов.
- Запуск из Always-on VPN по зашифрованному кэшу последнего плана сессии.
- `SoraTileService`: плитка быстрых настроек.
- Постоянное уведомление с действием отключения.

## Правила

- Форматирование и проверки: `ktlint` с настройками из корневого `.editorconfig`.
- Команды принимаются только от приложения Sora того же UID.
